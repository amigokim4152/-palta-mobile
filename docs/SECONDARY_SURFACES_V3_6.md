# Secondary surfaces v3.6

## Community

Community is not one giant public feed.

First depth:
- My groups
- Neighborhood
- Discover

Trust boundaries remain explicit:
- public local
- verified local
- member group
- private relation

Private membership never becomes public discovery by default.

## Market

Market is a browse surface, not a Post tab.

First verticals:
- Secondhand
- Vehicles
- Property
- Jobs & Services

Every vertical owns:
- search/filter grammar
- card/list grammar
- create schema

but shares:
- identity
- location
- media
- trust
- messaging
- Map Core where useful

Create/Post is contextual inside the selected vertical.

## Play

Play is not a lifestyle feed.

First sections:
- Eat & drink
- Events/culture
- Family
- Travel/stays

A confirmed real situation may create a temporary Context Space.
Browsing alone does not.
