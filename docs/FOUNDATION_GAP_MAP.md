# Foundation Gap Map — implementation-focused

Status values: EXISTING / PARTIAL / MISSING / LATER.

| Operational behavior | Status | Current authority / implementation destination |
|---|---|---|
| Home is private life state, not a menu | EXISTING | Product Core + Foundation Constitution |
| Started work continues through wait/result/follow-up | EXISTING | LIFE_NEED_CARE_CONTRACT + Product Core Event/Care flow |
| RESULT is not OUTCOME | EXISTING | LIFE_NEED_CARE_CONTRACT |
| Confirmed fact vs inference | EXISTING | Privacy/Trust + Personal Intelligence |
| Same canonical object reused across surfaces | EXISTING | Canonical Objects + Product Core ONE CANONICAL DATA |
| Exploration location must not silently become life area | PARTIAL | Product Core resident/exploring distinction; make explicit in Location Core |
| Sparse Home can show useful news/local/weather but does not fill for fullness | PARTIAL | Existing discovery-content allowance exists; wording should be made explicit in Home rules |
| No engagement-bait notification | PARTIAL | Quiet-until-needed + action-only Push already exist; explicit anti-engagement rule is useful |
| Accessibility | EXISTING | Experience Foundation layers + mobile quality gate |
| Offline/reconnect/state restoration | EXISTING | Experience Foundation + Infrastructure resilience |
| Push -> exact state via Deep Link | EXISTING | Experience Foundation |
| User correction / field reports | EXISTING | Product Core CorrectionReport/currentness loop |

| Specialist public web/domain surfaces sharing canonical data | PARTIAL | Public/Guest/cross-surface rules exist; specialist surface packaging is later implementation |
| Full legal proxy/guardianship | LATER | Deliberately not initial scope |

## Conclusion

Do not create another broad principles document. Most principles already exist in authoritative documents. The next artifact should be executable implementation contracts and tests. Only the sparse-Home wording and anti-engagement notification rule need small explicit clarifications in the authoritative Home/Discovery text when document editing is performed safely.
