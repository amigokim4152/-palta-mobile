# Presentation Priority Examples

## Weather

Normal state:
- frequent
- low risk
- low action requirement
- Glance Cluster

Severe weather:
- risk and urgency rise
- Alert / Action Surface depending severity

## Medication

Routine future dose:
- Glance or compact status

Dose due now:
- Action Surface

Dose recorded successfully:
- Success feedback + compact completed status

Missed dose requiring medical judgement:
- Do not improvise a dosage instruction.
- Surface official guidance / pharmacist / clinician path.

## Appointment

Future appointment:
- List Row

Appointment tomorrow with preparation:
- Primary status/action

Appointment time changed:
- Action Surface or alert depending impact

## News

Ordinary:
- Discover / text list

User is actively reading:
- Full Reading Surface

Large text:
- fewer metadata fields in list
- article content remains fully available

## Care

Current high-value state:
- Focus current state + next action

Historical steps:
- expandable/secondary timeline detail

The user should never need to understand the full state machine to know what to do next.
